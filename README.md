## 🚀 Overview

- **DataForge** is an automated **Data Quality Engine** built with Python and Streamlit that helps users evaluate the quality, consistency, completeness, and reliability of structured datasets.

- The platform allows users to upload a dataset and automatically perform essential data-quality checks, identify potential issues, generate statistical insights, and visualize important dataset metrics through an interactive dashboard.

- DataForge is designed to reduce repetitive manual data inspection and provide a centralized environment for understanding dataset quality before using data for analytics, machine learning, research, or other downstream workflows.

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

    git clone YOUR_GITHUB_REPOSITORY_URL

### 2️⃣ Navigate to Project

    cd automated-data-quality-engine

### 3️⃣ Create Virtual Environment

#### Windows

    python -m venv venv

#### macOS / Linux

    python3 -m venv venv

### 4️⃣ Activate Virtual Environment

#### Windows

    venv\Scripts\activate

#### macOS / Linux

    source venv/bin/activate

### 5️⃣ Install Dependencies

    pip install -r requirements.txt

### 6️⃣ Run Application

    streamlit run app.py

### 🌐 Local Application

    http://localhost:8501

## 🧪 How to Use

### 1️⃣ Launch DataForge

    streamlit run app.py

### 2️⃣ Upload Dataset

- 📄 Select a supported CSV dataset
- 📤 Upload it through the dashboard

### 3️⃣ Analyze Dataset

DataForge processes the uploaded dataset and performs the configured quality checks.

### 4️⃣ Review Results

Review:

- 📊 Dataset statistics
- ❌ Missing values
- 🔁 Duplicate records
- 🔤 Data types
- 📋 Dataset structure
- 📈 Quality metrics
- ⚠️ Potential data issues

### 5️⃣ Improve Dataset

Use the generated analysis to identify areas requiring data cleaning or further processing.
